Product overview

A frontend prototype for construction site operations. The reviewed interface includes project selection, task tracking, daily reports, materials, workforce and attendance, expenses, safety and inspection workflows. It stores local drafts in the browser; its current sync action updates local UI state and does not establish cloud synchronization.

  • Project dashboard and project selection
  • Task management and inspection logs
  • Daily site reports and PDF preview
  • Workforce attendance, expenses and safety workflows
  • Materials, challan scanning and material requests
